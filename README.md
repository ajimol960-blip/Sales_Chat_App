# U Commerce Chatbot

A real-time sales chat application featuring an interactive e-commerce chatbot built with FastAPI and WebSockets.

## Features

- **Real-time Chat:** Communicate with a chatbot instantly using WebSockets.
- **User Authentication:** Secure login and signup system.
- **Product Information:** Retrieves details about available products from the database.
- **Chat History:** Stores and loads past chat interactions for users.

## Technologies Used

- **Backend:** FastAPI, Python, PostgreSQL, SQLAlchemy
- **Frontend:** HTML, Bootstrap, JavaScript (WebSockets)

## Setup Instructions

1. Clone the repository.
2. Install the required dependencies using `requirements.txt`.
3. Configure your database and environment variables in the `.env` file.
4. Run the application using Uvicorn.
